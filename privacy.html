개인정보 처리방침

2026년 11월 23일부터 적용

승훈스 고정비앱 V1(이하 "앱")은 개인이 만들어 무료로 나누는 고정비 관리 앱이에요. 앱이 어떤 정보를 어디에 두는지 있는 그대로 적었어요.

한눈에 보기

  • 내가 적은 고정비 목록은 내 구글 계정 몫의 저장 공간에만 들어가요. 다른 사용자는 볼 수 없어요.
  • 결제일 일정은 내 구글 캘린더에만 만들어요.
  • 광고, 방문 분석 도구, 정보 판매는 없어요.

앱이 다루는 정보와 두는 곳

고정비 목록항목 이름, 금액, 결제일, 결제 수단 이름과 끝 4자리, 메모, 납부 체크 기록, 앱 설정(결제 전날 알림과 자동이체 자동 체크를 켰는지).
앱의 서버 역할을 하는 구글 Apps Script의 사용자별 저장 공간에, 로그인한 구글 계정 몫으로 따로 저장해요. 지운 항목은 "방금 지운 항목 되살리기"를 위해 같은 공간의 삭제 기록에 남아요.
결제일 일정캘린더 연동을 켜 두면 내 구글 캘린더에 하루 종일 일정으로 만들어요. 일정에는 항목 이름, 금액, 결제 수단, 메모가 들어가요. "결제 전날 알림"을 켜면 그 일정에 전날 오전 9시 알림을 붙이고, 알림은 구글 캘린더가 보내요.
구글 계정 이메일어떤 계정으로 로그인했는지 화면에 보여주고, 계정별로 저장 공간을 나누는 데만 써요.
이 기기에 남는 것로그인 표(1시간짜리 접근 토큰), 마지막으로 본 화면 내용(다음에 빨리 열려고), 쓰다 만 입력 내용. 브라우저 저장 공간에만 있고, 로그아웃하거나 계정을 바꾸면 지워요.

앱 주인 한 명은 예전 방식대로 자기 구글 시트에 목록을 둘 수 있어요. 다른 사용자의 구글 드라이브에는 파일을 만들지도 읽지도 않아요.

구글에 요청하는 권한

캘린더결제일 일정을 만들고, 고치고, 지워요. 구글 권한 화면에는 "모든 캘린더 보기·수정"으로 나오지만, 앱은 자기가 만든 결제일 일정만 바꿔요. 내가 만든 다른 일정은 바꾸지 않고, 어디에도 저장하거나 보내지 않아요. 공휴일 표시를 위해 "대한민국의 휴일" 캘린더를 읽어요.
스프레드시트앱 주인이 구글 시트 방식을 쓸 때만 써요. 다른 사용자의 시트는 열지 않아요.
스크립트 예약 실행매일 새벽에 캘린더를 한 번 맞추는 예약을 만들 때 써요. "자동이체 자동 체크"를 켰으면 그때 결제일이 지난 자동이체 항목도 낸 걸로 체크해요.
이메일 주소 보기로그인한 계정을 확인할 때 써요.

다른 곳에 전달되는 정보

  • 구글: 로그인, 목록 저장(Apps Script), 캘린더가 모두 구글 서비스라서 위 정보가 구글에 저장돼요.
  • GitHub Pages: 앱 화면 파일을 내려주는 곳이에요. 접속할 때 IP 주소 같은 접속 기록이 GitHub에 남을 수 있어요. 고정비 내용은 가지 않아요.
  • jsDelivr: 글꼴 파일을 내려받는 곳이에요. 마찬가지로 접속 기록만 남을 수 있어요.

이 밖에 누구에게도 정보를 팔거나 넘기지 않아요.

앱 만든 사람이 볼 수 있는 것

앱 만든 사람은 서버 코드를 관리해요. 구글이 보여주는 실행 기록(언제 어떤 기능이 실행됐는지, 성공했는지, 오류 내용)은 볼 수 있어요. 다른 사용자의 고정비 목록이나 캘린더를 들여다보는 화면이나 기능은 없고, 목록 내용을 따로 기록하지도 않아요.

지우기와 그만 쓰기

  • 항목은 앱에서 지울 수 있어요. 캘린더 일정은 내 구글 캘린더에서 직접 지울 수 있어요.
  • 앱 메뉴(⋯)의 로그아웃을 누르면 이 기기에 남은 내용이 지워져요.
  • 구글 계정 → 서드 파티 앱 및 서비스에서 이 앱의 권한을 언제든 끊을 수 있어요. 권한을 끊으면 앱은 내 정보에 더는 접근하지 못해요.
  • 앱에서 지운 항목은 목록에서 빠지지만, 되살리기용 삭제 기록에는 남아요. 서버 저장 공간을 한 번에 비우는 기능은 아직 없어요.
